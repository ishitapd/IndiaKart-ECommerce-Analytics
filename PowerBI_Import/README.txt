IndiaKart Power BI import package

1. Open Power BI Desktop.
2. Select Home > Get data > Text/CSV.
3. Import orders_clean.csv and order_items_clean.csv first.
4. Import the remaining KPI CSV files as supporting report tables.
5. Use PowerBI_dashboard_guide.md for relationships, DAX measures, and report page layout.
6. Save the completed report as IndiaKart_Ecommerce_Analytics.pbix.

The existing Streamlit dashboard remains available at http://localhost:8501.
